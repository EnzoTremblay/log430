# Rapport du Laboratoire 0

## Résumé
Ce laboratoire porte sur la structuration d’un dépôt, la mise en place d’une application minimale, la configuration de la CI/CD et la conteneurisation.

## Éléments réalisés
- README.md complet
- .gitignore pertinent
- Application Python fonctionnelle
- Tests unitaires
- Dockerfile et docker-compose.yml
- CI/CD avec GitHub Actions
- Documentation technique (ADR, UML)

## Difficultés rencontrées

- Mise en place de la pipeline CI/CD

## Améliorations possibles
