# ADR 2 : API Gateway et Observabilité

## Contexte
La gestion centralisée des accès et la visibilité sur les services sont essentielles.

## Décision
Mise en place d’une API Gateway (KrakenD) pour le routage, la sécurité et le monitoring.

## Conséquences
- Point d’entrée unique et sécurisé
- Monitoring et observabilité centralisés
- Load balancing et résilience
