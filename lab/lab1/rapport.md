# Rapport du Laboratoire 1

## Résumé
Ce laboratoire porte sur la gestion de produits, la persistance avec SQLAlchemy, la documentation technique et la CI/CD.

## Éléments réalisés
- Application client pour la gestion de produits
- Persistance avec SQLAlchemy et SQLite
- Documentation technique (ADR, UML)
- Dockerfile et docker-compose.yml
- CI/CD avec GitHub Actions
- Tests unitaires

## Difficultés rencontrées
- Configuration de la pipeline CI/CD
- Gestion des secrets

## Améliorations possibles
- Automatisation accrue des tests
- Documentation plus détaillée
