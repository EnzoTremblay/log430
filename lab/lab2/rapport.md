# Rapport du Laboratoire 2

## Résumé
Ce laboratoire porte sur l’architecture logicielle, la documentation technique selon Arc42, la justification des choix via ADR, et la mise en place d’un code source fonctionnel.

## Éléments réalisés
- Code source complet et fonctionnel
- Rapport structuré (Arc42)
- Deux ADR pour les décisions majeures
- README.md avec instructions de déploiement
- Documentation technique (diagrammes UML, etc.)
- Captures d’écran ou liens vers les dashboards d’observabilité

## Difficultés rencontrées
- Structuration du rapport Arc42
- Justification des choix architecturaux

## Améliorations possibles
- Documentation plus détaillée
- Ajout de dashboards d’observabilité
