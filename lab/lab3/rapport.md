# Rapport du Laboratoire 3

## Résumé
Ce laboratoire porte sur l’exposition d’une API RESTful pour le système multi-magasins, la documentation technique, la sécurisation et les tests d’API.

## Éléments réalisés
- API RESTful exposant les principales fonctionnalités métier
- Documentation Swagger (OpenAPI)
- Sécurisation (CORS, authentification)
- Tests d’API et intégration CI/CD
- Instructions d’exécution et exemples de requêtes

## Difficultés rencontrées
- Structuration des routes REST
- Documentation Swagger
- Sécurisation des endpoints

## Améliorations possibles
- Ajout de tests d’intégration plus poussés
- Extension de l’API pour de nouveaux cas d’usage
